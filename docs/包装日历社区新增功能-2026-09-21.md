# 包装、日历、社区新增功能

## 已实现

- 包装实时 SVG 示意：礼盒、丝带颜色/绑法、文字、贺卡及所选装饰随配置变化；支持浏览器本地导出 SVG。照片夹是占位图，预览不代表实物尺寸，未接入 AI 图片生成或实物照片上传。
- 日历月视图：前后月份切换、重复事件展示、点击事件进入编辑；闰日按原业务规则处理。保留原有事件清单。
- 本月 ICS 导出：导出本月实际发生的单次全天事件，保留稳定 UID，正确转义标题和折叠 UTF-8 长行。不导出私有画像，也不创建无限重复规则或同步外部日历账号。
- 社区举报：原因及说明必填，一人对同一帖子只保存一份举报。举报不会自动隐藏内容，避免通过恶意举报直接下架帖子。
- 审核队列：授权人员可分页查看待审/已隐藏/已驳回举报、查看原文并填写审核说明；支持隐藏或驳回，记录审核人员及决定。重复审核返回冲突，防止覆盖已有决定。
- 普通用户不能读取审核队列或执行审核；审核原文也沿用匿名脱敏，不直接显示匿名作者身份。

## 启用方式

新版本需重新启动前后端。数据库表由 schema.sql 幂等创建，未改动当前运行的业务数据库。

审核权限默认关闭。在后端环境变量 `COMMUNITY_MODERATOR_IDS` 中配置真实审核账号的数据库用户 ID，多个 ID 以英文逗号分隔。这不是手机号，也不是前端提交的角色信息。未为任何账号自动授予权限。

授权账号登录后，社区页面会出现“处理社区举报”，也可访问 `/stories/moderation`。未配置审核员时举报仍会记录，但需要配置审核员后才能处理。隐藏是软隐藏，原文保留；本轮不包含恢复已隐藏帖子的后台入口。

## 验证

- 后端 `mvn package -q`：27 项测试通过，无失败、无跳过。
- 前端 `npm run lint`、`npx tsc --noEmit`、`npm run build`：通过。
- `node --test tests/calendarExport.test.cjs`：2 项通过，验证重复日期、闰年、跨年 DTEND、ICS 转义及 UTF-8 折行。
- 审核单元测试覆盖权限、重复举报、处理冲突、驳回和匿名原文。内存 H2 验证新表及联合唯一约束。
- 未进行浏览器视觉验收，未登录第三方日历账号，未调用付费服务，未推送远程。
