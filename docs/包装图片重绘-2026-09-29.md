# 包装图片重绘 · 2026-09-29

使用内置 image_gen 生图模型，每个选项单独生成一张图片（共 15 张），未使用 CLI 或矢量占位图。
最终素材：`frontend/giftgpt-web/public/packaging/*.jpg`，从生成的 PNG 编码为 JPEG（质量 88），不改变画面。
原始 PNG 保留在生图工具输出目录。统一暖象牙白背景、柔光摄影与真实材质；绑法、配件按选项名称分别呈现。

页面以固定样图展示搭配，不伪装为实时组合渲染；导出的 PNG 含所选图片及实际定制文字、颜色、香型。

## 完整提示词与素材映射

验证结果：`npm run lint`、`npm run typecheck`、`npm run build` 均通过；本地 Chromium 5 项浏览器测试在开发服务及正式构建下均通过。
测试文件：`tests/e2e/packaging-raster.spec.js`。覆盖 15 张 JPEG 加载、礼盒/绑法切换、PNG 导出、保存请求字段、历史方案回显、手机布局及图片加载失败提示。接口使用模拟数据，未写入真实业务数据。
旧的 15 张包装 SVG 已被对应 JPG 替换，可从 Git 历史恢复。上述验证在本地完成，上线状态以 GitHub Actions 部署记录及公网图片校验为准。
